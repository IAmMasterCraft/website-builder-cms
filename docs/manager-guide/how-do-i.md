# How do I…?

Everyday tasks, with where to find them. "Admin → X" means: log in, then
click **X** in the menu on the left (open its group first if it is folded,
for example **Radio** for Library, Playlists and Schedule).

## The website

| How do I… | Where |
|---|---|
| …change the organisation's name, contact details or logo? | Admin → **Site settings**. See [Site settings](settings.md) |
| …change the icon in browser tabs (favicon)? | Admin → **Site settings** → **Site icon (favicon)**. See [Site icon](settings.md#site-icon-favicon) |
| …change the colours, fonts or theme? | Admin → **Design**. See [Design and themes](design.md) |
| …add a page? | Admin → **Pages** → **New page**. See [Pages and the page builder](page-builder.md#creating-a-page) |
| …edit the home page? | Admin → **Pages** → **Build** next to "Home" |
| …add a photo banner, numbers, testimonials… to a page? | In the page builder, **Add section**. See [every section type](page-builder.md#every-section-type) |
| …make a page visible to members only? | Admin → **Pages** → **Edit** → **Visibility: Members only** |
| …change which page is the home page? | Open the page → tick **Use as the home page** |
| …add or reorder items in the main menu? | Admin → **Menus** → the menu → **Add an item** / **Move up**. See [menus](header-footer-menus.md#menus) |
| …change the footer? | Admin → **Header and footer**. See [the footer](header-footer-menus.md#the-footer) |
| …upload a photo or document? | Admin → **Media library** → **Upload files**. See [Media library](media-library.md) |
| …stop a photo's important part being cut off? | Media library → the photo → **Focal point**. See [focal points](media-library.md#focal-points) |
| …switch on visitor statistics (analytics)? | Admin → **Site settings** → **Analytics and cookies** |
| …show donation details? | Admin → **Site settings** → **Donations**, then a **Donate** section or footer widget |

## Content

| How do I… | Where |
|---|---|
| …post news? | Admin → **Posts** → **New post**. See [Posts](posts.md) |
| …schedule a post for later? | Status **Scheduled** and a future **Publish date** |
| …add an event and let people register? | Admin → **Events** → **New event**, tick **Registration open**. See [Events](events.md) |
| …see who registered for an event? | Admin → **Events** → the event → **Registrations** |
| …check people in at the door? | The registrations list → **Check in** |
| …add a photo album? | Admin → **Gallery** → **New album**, then **Manage photos**. See [Gallery](gallery.md) |
| …share a document (minutes, constitution)? | Admin → **Downloads** → **New download**. See [Downloads](downloads.md) |
| …update the committee? | Admin → **Leaders**. See [Leaders](leaders.md) |
| …add an award winner? | Admin → **Awards**. See [Awards](awards.md) |
| …add a frequently asked question? | Admin → **FAQ**. See [FAQs](faqs.md) |
| …list a local branch? | Admin → **Branches**. See [Branches and groups](branches-groups.md) |

## Members

| How do I… | Where |
|---|---|
| …find a member? | Admin → **Members** → search by name, email, number or phone |
| …change a member's details or expiry date? | Admin → **Members** → the member. See [Members](members.md) |
| …print member cards? | Admin → **Members** → tick members → **Print selected cards** |
| …give a member a new password? | The member → **Email a password link** |
| …suspend or remove a member? | The member → **Suspend**, or **Remove member** (type DELETE) |
| …handle a deletion request? | Members → status filter **Deletion requested** → the member → **Remove member** |
| …import members from a spreadsheet? | Admin → **Members** → **Import CSV**. See [Import](members.md#importing-members-from-a-spreadsheet) |
| …export the member list? | Admin → **Members** → **Export CSV** |
| …ask members an extra question at sign-up? | Admin → **Custom fields** → **New field** |
| …ask members their state of origin and LGA? | Admin → **Membership settings** → **Origin on the sign-up form**. See [Membership settings](members.md#membership-settings) |
| …list or email everyone from one state (or country)? | Members → **Filter by location**; for email, a campaign with the audience **Members by location**. See [Location fields](members.md#location-fields) |
| …add a local area that is missing from the list, or rename "Local Government Area"? | Admin → **Location lists**. See [Location lists](members.md#location-lists) |
| …show a member's state of origin on their card? | Admin → **Membership settings** → **Location on the card** |
| …change member number format or card validity? | Admin → **Membership settings** |
| …approve a job post? | Admin → **Jobs**. See [Job board](jobs.md) |
| …deal with a reported comment? | Admin → **Comments**. See [Comments and reports](comments.md) |
| …see exactly what a member sees, to help them? | The member → **Log in as this member**. See [Log in as a member](members.md#log-in-as-a-member) |

## Communications

| How do I… | Where |
|---|---|
| …send a newsletter? | Admin → **Campaigns** → **New campaign**. See [Campaigns](campaigns.md) |
| …send the AGM notice to every member? | A campaign with **Essential membership notice** ticked. See [essential notices](campaigns.md#essential-membership-notices) |
| …post an announcement on members' dashboards? | Admin → **Notices** → **New notice**. See [Notices](notices.md) |
| …answer a message from the contact form? | Admin → **Inbox** → the message → **Reply by email**. See [Inbox](inbox.md) |
| …change the wording of the welcome email? | Admin → **Email templates** → **Welcome (with member number)**. See [Email templates](email-templates.md) |
| …see whether emails were delivered? | Admin → **Delivery log**, or the campaign's **Delivery log** |
| …find out why someone does not get our emails? | Admin → **Suppression list**. See [Email settings](email-settings.md#suppression-list) |
| …set up sending email? | Admin → **Email settings** *(super admin)*. See [Email deliverability](../email-deliverability.md) |

## Radio

| How do I… | Where |
|---|---|
| …upload a programme? | Admin → **Library** (under Radio) → **Upload a programme**. See [Radio](radio.md) |
| …put a show on air at a set time? | Admin → **Schedule** → **Add a slot** |
| …play music when nothing is scheduled? | Make a playlist, then Library → **Station** → **Fallback loop** |
| …switch the station off? | Library → **Station** → untick **Station switched on** |

## Running the site

| How do I… | Where |
|---|---|
| …change my own password, email or name? | Your name at the top right → **My profile**. See [First login](first-login.md#your-own-profile) |
| …add another admin? | Admin → **Users and roles** → **New admin**. See [Users and roles](users-roles.md) |
| …see who changed something? | Admin → **Audit log**. See [Audit log](audit-log.md) |
| …make a backup? | Admin → **Backups**. See [Backups and restore](backups.md) |
| …check the site is healthy? | Admin → **System health**. See [System health](system-health.md) |
| …update to a new version? | See [Updating the site](updating.md) |
| …fix a problem? | See [Troubleshooting](troubleshooting.md) |
| …find help for the screen I am on? | Click **Help** next to the screen's title, or **Help centre** at the bottom of the menu. See [The help centre](help-centre.md) |
| …search all the guides? | **Help centre** → **Search the help** |
| …tidy up the menu on the left? | Click a group's name to fold it, or **Collapse all**. The folded/unfolded state is remembered. See [Finding your way around](first-login.md#finding-your-way-around) |
| …let only members read the member guide? | Admin → **Site settings** → **Help and member support** |
| …publish these guides as a website? | See [Publishing the documentation as a website](../docs-website.md) |
